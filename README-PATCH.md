# CC GUI с правкой: отправка мимо очереди

Это копия исходников CC GUI (ветка `local/cmd-enter-send-now` от тега `v1.1.9`)
со своей правкой. Собранное приложение лежит здесь:

```
src-tauri/target/release/bundle/macos/CC GUI.app
```

## Что делает правка

В приложении было одно действие отправки: пока агент отвечает, сообщение
вставало в очередь и уходило только после конца текущего ответа. Добавлены
два жеста:

| Клавиши | Что происходит |
|---|---|
| `⌘ + Enter` | текущий ответ прерывается, моё сообщение уходит следующим — то же, что кнопка «Send» на карточке в очереди |
| `⌃ + Enter` | сообщение вклинивается в идущий ответ, не прерывая агента (движок pi: он видит его после текущего шага с инструментами) |
| `Enter` | как было: отправить, а если агент занят — встать в очередь |
| `Shift + Enter` | перенос строки |

Очередь при этом не ломается: `⌘ + Enter` не отменяет уже стоящие в ней
сообщения — они уходят после. Оба жеста перечислены в окне «Горячие клавиши».

Ограничения:

* `⌃ + Enter` работает только с движком **pi** (у остальных нет канала, по
  которому можно передать сообщение в идущий ответ). Для других движков
  `⌃ + Enter` делает то же, что `⌘ + Enter`.
* У совсем нового чата, где сессия ещё не получила свой номер, вклинить тоже
  нельзя — сообщение уйдёт сразу, как по `⌘ + Enter`.

## Как пересобрать

```bash
./build-patched.sh
```

Скрипт отличается от штатного двумя вещами: подпись ставится своя (ad-hoc),
и не собираются артефакты обновления — для них нужен приватный ключ автора
приложения, а для подписи его сертификат. Оба шага приложение выполняет при
сборке, поэтому подменить их нельзя.

Сборка идёт 20–40 минут в первый раз (компилируется вся серверная часть),
дальше быстрее — уже собранное переиспользуется.

## Когда выйдет новая версия CC GUI

```bash
git fetch --tags origin
git checkout -B local/cmd-enter-send-now <новый-тег>
git cherry-pick <наш-коммит>      # или git rebase
./build-patched.sh
```

Правка — один коммит (`git log --oneline` в этой папке). Наши изменения
затрагивают только ввод текста, отправку, окно горячих клавиш и три словаря,
поэтому с новыми версиями переносятся без разборок.

## Про обновления внутри приложения

Собранная копия — обычное приложение с тем же именем и тем же внутренним
идентификатором, что и официальное, и настройки у них общие
(`~/.ccgui-next`). Но обновление, которое приложение предложит само, поставит
официальную сборку и затрёт правку. Обновлять — только через пересборку выше.
